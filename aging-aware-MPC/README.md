# Original aging coefficient tables

This directory contains only the two unchanged coefficient tables required by dad.benchmark_b2_tables, and the upstream BSD 3-Clause license.

Source: Nils Collath and collaborators, [aging-aware-MPC](https://gitlab.lrz.de/open-ees-ses/aging-aware-MPC), associated with Applied Energy 348 (2023), 121531. The research copy was audited against upstream commit 833f9252e703ec0c64f9eb007b323d46d139f52e. Exact CSV hashes are enforced by src/dad/benchmark_b2_tables.py and recorded in reproducibility-sha256.txt.

No upstream main program or Gurobi workflow is included. Follow reproduce.md in the repository root for this project.
